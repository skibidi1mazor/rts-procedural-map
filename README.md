# RTS génération procédurale

Projet Python/Pygame proposant une carte hexagonale RTS générée procéduralement.

## Structure prévue

- `calcul.py` : génération de carte, relief, biomes, rivières et caméra
- `render.py` : affichage Pygame
- `main.py` : boucle principale du programme
- `Tuto.md` : explication pédagogique du fonctionnement

## Installation

Le projet utilise Pygame. Installe les dépendances avec :

```bash
python -m pip install -r requirements.txt
```

## Lancement

```bash
python main.py
```
